# 🔐 Cipher Lab

Cipher Lab is a Python project that implements **Cryptographic Algorithms**. It provides a simple terminal-based interface where users can choose a cipher, enter plaintext and a key to generate the encrypted output.

---

## 📖 Background

I built this project after learning cryptographic algorithms in my **Computer and Cyber Security** course.

After completing my mid-term examination, I decided to turn the theoretical concepts into a practical Python project by implementing each algorithm from scratch.

This project is part of my learning journey to strengthen my understanding of cryptography, improve my Python programming skills and build a clean, modular collection of cipher algorithms.

---

## ✨ Features

- Terminal-based user interface
- Modular and beginner-friendly codebase
- Separate module for each cipher algorithm
- Easy to extend with new cipher implementations
- Educational implementation of cryptography

---

## ✅ Currently Implemented

- Additive Cipher
- Multiplicative Cipher

## ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/hoqueeprobal/CipherLab.git
```

Navigate to the project directory:

```bash
cd CipherLab
```

Run the application:

```bash
python ciper-lab.py
```
